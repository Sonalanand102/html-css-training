loop : A loop is a programming structure that allows us to execute a block of code repeatedly based on a particular condition or sequence.

1. for : A for loop is used to iterate over a sequence or any iterable object, executing a block of code for each item.

Examples of iterables include:
- Strings.
- Lists.
- Tuples.
- Sets.
- Dictionaries.
- Ranges.

2. while : A while loop repeatedly executes a block of code as long as the given condition evaluates to True.

## Loop Control Statements 

1. break : The break statement immediately terminates the nearest enclosing loop, even if the loop condition is still true or more items are available.
2. continue : The continue statement skips the remaining statements in the current iteration and moves to the next iteration.
3. pass : The pass statement is a null operation. It does nothing when executed.
